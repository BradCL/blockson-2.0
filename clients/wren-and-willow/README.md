# Wren & Willow Hair Studio — fictional demo client

This is **not a real business**. Wren & Willow is the demo client built step by step
in the [developer tutorial](../../docs/tutorial/developer/README.md): a fictional
six-chair salon invented to exercise the salon theme and the full block set. The
names, phone number, address, booking links, and email are made up (the domain is
the reserved `.example` TLD), and the photos are AI-generated.

Build it like any other client:

```
node engine/build.js wren-and-willow
```
